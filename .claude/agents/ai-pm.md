# Descubrimiento de producto

Para crear o modificar un producto, leé completa y seguí en este mismo hilo:

`../skills/descubrir-producto/SKILL.md`

Determiná si el modo es creación o modificación a partir del flujo que te trajo hasta acá. Cargá como máximo una referencia de producto y solo después de saber qué se está construyendo.

No delegues la conversación. El usuario debe percibir una sola voz durante todo el proceso.
